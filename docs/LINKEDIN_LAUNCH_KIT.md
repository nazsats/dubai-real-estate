## 0. The best way to launch this (recommendation)

**Lead with a 45–60 second screen-recorded demo video, not screenshots.** For an AI SaaS,
showing the AI *doing the work live* (type a request → watch it match + write a pitch) beats
any static image. Then reuse stills as a carousel.

Priority order of formats on LinkedIn (highest reach → lowest):
1. **Native video demo** (45–60s, screen recording with captions) — best for a "wow" launch.
2. **Carousel / PDF** (6–8 slides, one feature per slide) — best for explaining features.
3. **Single strong screenshot + story text** — good for ongoing "build in public" posts.

Tools (free): **Loom** or **ScreenPal** or Windows **Game Bar (Win+G)** to record; **Canva**
for the carousel; ** shots.so / screely** to put your screenshots in a clean browser frame.

## 1. How to capture great screenshots

- **Use real data first:** run `import_listings.py 3 --fresh` so listings/market look real;
  add ~10 leads so Pipeline/Today aren't empty.
- **Dark theme = premium.** Your app is already dark — it photographs well. Full-screen the
  browser (F11), hide bookmarks, zoom to 90–100%.
- **Capture at 1920×1080** if possible (clean 16:9 for LinkedIn).
- **Frame them:** drop each shot into shots.so for a browser mockup + soft shadow.
- Blur any real phone numbers/emails if you used real leads.

## 4. Marketing strategy & best practices

**Cadence:** post 2–3×/week for 3–4 weeks, not once. One launch post, then one feature per
post. Consistency compounds reach.

**Hooks matter most.** First line decides if anyone reads. Use a pain or a number:
*"Brokers lose 40% of leads to slow follow-ups."* / *"I built an AI that writes a broker's pitches in 5 seconds."*

**Engagement tactics**
- End every post with a question or a "comment DEMO" CTA (comments > likes for reach).
- Reply to every comment in the first 2 hours (LinkedIn boosts active posts).
- Put external links in the **first comment**, not the post (links in-post reduce reach).

**Who to target / where to post**
- LinkedIn: Dubai real-estate agents, agency owners, PropTech groups.
- Also post in: Dubai real-estate **WhatsApp/Telegram broker groups**, **Reddit r/dubai**,
  X/Twitter (build-in-public), and Instagram (carousels + reels of the demo).

**Hashtags (5–8):** #DubaiRealEstate #PropTech #RealEstateTech #AI #Dubai #UAE #BuildInPublic #SaaS

**Positioning:** sell the *outcome*, not the tech — "close more deals with less busywork,"
"never forget a follow-up," "pitch in any language in seconds." Brokers care about time + commission.

**Lead magnet:** "Comment DEMO" → DM them a 60-sec Loom + a calendar link. Collect early users.
