# Free APIs & data to level up the product

Curated, mostly-free options that fit a Dubai real-estate agent tool. ✅ = no key needed.

## Maps & location
- **OpenStreetMap + Leaflet** ✅ — already used for the UAE market map (CARTO dark tiles, no key).
- **Nominatim (OSM) geocoding** ✅ — turn an address/area into lat/lng. Fair-use limits.
- **Mapbox** (free tier, key) — prettier 3D/satellite tiles if you want to upgrade visuals.
- **Overpass API** ✅ — nearby amenities (schools, metro, malls) around a listing for "what's nearby".

## Real Dubai property / transaction data
- **Dubai Pulse / DLD open data** (dubaipulse.gov.ae) — the Dubai Land Department publishes
  **real transaction datasets** (sales, rents, projects). Gold for genuine price trends and a
  "recent comparable sales" feature. Bulk/CSV + some APIs; free with registration.
- **Dubai REST** (DLD app ecosystem) — official records; access varies.
- *(Bayut / Property Finder have no free public API — Phase 7 uses DLD data or sanctioned feeds.)*

## Money / market context (great for international buyers)
- **exchangerate.host** ✅ or **open.er-api.com** ✅ — live AED↔USD/EUR/GBP/INR/RUB for budget
  conversion ("AED 5M ≈ $1.36M"). Very useful for foreign clients.
- **Frankfurter** ✅ — ECB FX rates, simple and free.

## Content & media
- **Unsplash API** (free tier, key) — high-quality stock photos for listings/marketing mockups.
- **GNews / NewsData.io** (free tier, key) — a "Dubai real-estate news" widget for the dashboard.
- **REST Countries** ✅ — client nationality data for personalization.

## Comms (already in plan)
- **Telegram Bot API** ✅ — what we're using now (free, instant).
- **WhatsApp Cloud API** — later; conversation-based pricing + business verification.

## Utility
- **OpenWeather** (free tier, key) — small "weather at the community" touch for viewings.
- **ipapi.co / ipinfo** (free tier) — rough geo of inbound web leads.

## Highest-impact picks for THIS product
1. **DLD / Dubai Pulse transactions** → real trend charts + comparable-sales (huge credibility).
2. **exchangerate.host** → multi-currency budgets for international buyers (1-hour build).
3. **Overpass "what's nearby"** → enrich each listing with metro/schools/malls.
4. **Unsplash** → instant marketing visuals to pair with the AI marketing copy.
